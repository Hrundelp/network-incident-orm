# Журнал инцидентов промышленной сети

Проект на Python 3.12+ хранит сведения об устройствах, инцидентах и действиях по их устранению в SQLite.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m examples.crud_demo
```
